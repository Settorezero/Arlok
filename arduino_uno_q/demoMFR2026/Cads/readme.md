### Crowvision Assembly

Here are the parts used for attaching the Arduino Uno Q and the Official Arduino USB Hub on the back of an Elecrow Crowvision 11.6" LCD Screen. This is not needed since you can use a common laptop or a phone for connecting to the Arduino UNO Q on your robot, anyway both devices (robot and controller) have to be connected to the same Wi-Fi network.

##### Notes

- Use the USB 5V Out from screen for powering the Arduino USB Hub

- 3mf file is for bambulab 3D printers

- Crowvision display uses uncommon M2.5 screws
